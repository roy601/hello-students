# 16 — Wireframes

Low-fidelity layouts for every screen on the critical path. These fix **information hierarchy and control placement**, not visual design — no colour, type or spacing decisions are implied here.

Conventions used in these sketches:

```
[ Button ]      primary action        ( Button )   secondary action
[▾ Select ]     dropdown              [ ⌕ input ]  text field
◉ ○             radio                 ☑ ☐          checkbox
▓▓▓░░           progress / rating      ⋯            overflow menu
🔴 🟠 🟡 🟢      status severity        ⚠            warning state
```

Reading order below follows the marketplace loop: **student discovers → books → pays → attends → reviews**, then the tutor and admin surfaces that support it.
